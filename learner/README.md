# K線學堂 — 股票技術分析學習器

單一檔案的靜態網頁（`learner/index.html`），不需安裝套件或建置，直接用瀏覽器開啟即可；部署到 Vercel 後路徑為 `/learner/`。

## 功能

- **課程**：9 堂互動課（K線、均線、成交量、支撐壓力、RSI、KD、MACD、布林通道、風險與成本），每課附可互動的 K 線圖與自動標記的訊號。
- **圖表實驗室**：自由開關均線 / 布林 / 支撐壓力 / RSI / KD / MACD，游標所在 K 棒會即時顯示多空判讀；可對 6 種策略做回測（隔日開盤成交，含 0.1425% 手續費與 0.3% 證交稅），並與買進持有比較。
- **判讀挑戰**：看 120 天走勢，預測接下來 10 天漲或跌，揭曉後對照作答當天的指標檢討。
- **觀念測驗**：14 題選擇題，附解析。

## 資料

價格皆為程式模擬（趨勢段落切換 + 波動叢聚，±10% 漲跌幅限制，價格貼齊台股升降單位），僅供學習，不代表任何個股。
學習進度、最佳成績存在瀏覽器 localStorage。
