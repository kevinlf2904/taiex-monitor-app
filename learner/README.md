# K線學堂 — 股票技術分析學習器

單一檔案的靜態網頁（`learner/index.html`），不需安裝套件或建置，直接用瀏覽器開啟即可；部署到 Vercel 後路徑為 `/learner/`。

## 功能

- **課程**：23 堂互動課，分成七組，每課附可互動的 K 線圖與自動標記的訊號，可按「換一段走勢」看更多例子。
  - 基礎：K 線
  - K 線與型態學：反轉型態、持續型態與跳空缺口（17 種 K 線型態卡片）、型態學（頭肩頂 / 底、M 頭、W 底、上升 / 下降 / 對稱三角、箱型，畫出頸線與測量目標）
  - 趨勢與量價：道氏理論（HH / HL / LH / LL 轉折標示、三階段圖解）、均線、成交量、內外盤（可操作的模擬五檔報價與每日外盤比）、支撐壓力、斐波那契回撤與延伸（自動挑選最近的明顯波段，標出 23.6%～78.6% 回撤、127.2% / 161.8% 延伸與第一次回測黃金區）
  - 技術指標：RSI、KD、威廉指標 %R（含台股軟體 0～100 刻度的差異）、MACD、布林通道
  - 背離：一般背離、隱藏背離（RSI / MACD / KD）
  - 聰明錢概念（SMC，五堂）：市場結構（轉折點定義、BOS 與 CHoCH 的差別、收盤確認、內外部結構、多時間框架）、流動性（BSL / SSL、等高 / 等低點 EQH / EQL 自動標示、誘導、掃蕩與真突破的分辨）、訂單塊（定義、有效條件、回測進場與停損、突破塊）、公平價值缺口（CE 50%、反向 FVG、與訂單塊重疊）、溢價 / 折價區與 OTE 最佳進場區，以及六步驟的完整交易流程；每堂都附示意圖
  - 風險管理
  - 所有轉折點、背離、結構突破與型態都只用「當時已確認」的資料判斷，標記畫在確認日，不偷看未來。
- **圖表實驗室**：自由開關均線 / 布林 / 支撐壓力 / RSI / KD / MACD，游標所在 K 棒會即時顯示多空判讀；可對 6 種策略做回測（隔日開盤成交，含 0.1425% 手續費與 0.3% 證交稅），並與買進持有比較。策略包含 K 線型態、RSI / MACD 背離、威廉指標、型態學突破、聰明錢 CHoCH 與道氏結構突破；主圖可疊加轉折點結構、訂單塊 / 缺口與斐波那契，副圖可切換威廉指標與外盤比。
- **判讀挑戰**：看 120 天走勢，預測接下來 10 天漲或跌，揭曉後對照作答當天的指標檢討。
- **截圖判讀**：上傳、拖曳或貼上看盤軟體的 K 線截圖，全部在瀏覽器內處理：
  - K 棒：先從飽和、有寬度的實體學出「K 棒本身的顏色」，只認這兩種顏色，並排除扁平的筆畫，所以圖上有均線（含紅、綠色均線）、空心 K 棒、深色主題都能辨識；被遮住的 K 棒以虛線估計補上，避免指標錯位；最新價標籤、十字游標、紅綠報價文字、JPEG 壓縮、縮放過的圖、極密集 K 棒、圖表外的紅綠元素都有處理。被均線穿過、切成上下兩段的 K 棒會接回同一根（上下引線不再被截掉）；最左、最右的極端價 K 棒和其他 K 棒隔著空白時也會沿 K 棒間距找回來；平盤畫成白色十字的 K 棒也會讀到。和 K 棒同色的圖上文字（最高 / 最低價標示，含斜體、數字黏成一長條的情況）、SAR 圓點、訊號三角形會依形狀排除：K 棒每一列只有一段、且有一欄從頂連到底，數字則有洞、孤立在 K 棒上方或下方，所以標籤不會再被當成最高那根 K 棒的上引線而拉歪整張圖的價格換算；整張手機 App 截圖（含報價、表格、圖例）可直接上傳，預設只顯示圖表區。
  - 副圖：自動找出價格區下方的成交量、KD、RSI、MACD 副圖，直接讀取截圖上的指標線與柱狀體（交叉、柱體放大縮短、零軸、鈍化、與價格的背離）。類型可手動更改；框選副圖並填入框頂 / 框底數值即可判斷高低檔。
  - 聰明錢（SMC）：由重建的 K 棒判斷結構（BOS / CHoCH）、流動性掃蕩、等高 / 等低點、溢價 / 折價區，以及上下方尚未回測的訂單塊與公平價值缺口，附教學用的情境推演；區塊與結構線可直接疊在原始截圖上。
  - 結果分成「總覽 / 聰明錢 / 副圖 / Claude 解讀」分頁；截圖可放大檢視。
  - 重建工具：在截圖上點兩條價格格線做兩點校正（點擊會自動吸附到偵測到的格線，比輸入最高 / 最低更準）、填最後一根日期自動推算交易日、「修正 K 棒」可刪除誤判、改漲跌顏色或補上漏掉的 K 棒。
  - 圖上的實際數字：填入（或按「讓 Claude 讀出數字」自動填入）商品名稱、圖上標示的最高 / 最低、資料列的日期與開高低收、它是倒數第幾根（游標停在別根時用）。最高最低用來換算全部 K 棒的價格；開高低收直接取代那一根的讀值並和程式讀值並列對照；重建圖上畫出圖上最高、最低與收盤線；模擬改以實際數字為起點，並算出再創圖上最高、跌破圖上最低的機率。
  - 未來走勢模擬（附「這個模擬參考了什麼？為什麼長這樣？」說明：資料來源、抽樣方式與漲跌分布、方向的計算過程與數字、範圍為什麼隨時間變寬、代表性 K 線的開盤與引線怎麼來；另算出回到斐波那契 61.8% 的機率）：以截圖近期的每日漲跌幅做蒙地卡羅抽樣（800 條路徑），畫出 25–75%、10–90% 機率帶、中位數與一條代表性路徑（代表性路徑的上下引線從原股票近期真實 K 棒的上影線、下影線比例抽樣，保留它的個性），並統計收高機率、碰到上方空方區塊 / 跌到下方多方區塊的機率；情境可選延續近期趨勢、純隨機、依技術指標偏向、依聰明錢結構。只是可能性的範圍，不是預測。
  - 可框選 K 線區或副圖重新辨識。圖片不會離開瀏覽器，除非按下「請 Claude 解讀」。
- **觀念測驗**：32 題題庫，每次隨機抽 12 題，附解析。

## 手機版

螢幕寬度 640px 以下時，主選單移到畫面底部。

## 圖表操作

截圖重建、實驗室、判讀挑戰的圖表上方有技術指標開關（主圖：MA5 / 10 / 20 / 60、布林、支撐壓力、聰明錢、轉折結構、K 線型態、型態學；副圖可多選疊加：成交量、KD、RSI、MACD、威廉、外盤比、截圖副圖），選擇會記在瀏覽器裡。

所有 K 線圖都能縮放與平移：右上角的 − / ＋ / 全部按鈕、Ctrl（⌘）＋滾輪或觸控板雙指縮放、手機雙指縮放、拖曳平移，雙擊還原。

## 資料

價格皆為程式模擬，內外盤量也是依當日漲跌加上雜訊模擬（趨勢段落切換 + 波動叢聚，±10% 漲跌幅限制，價格貼齊台股升降單位），僅供學習，不代表任何個股。
學習進度、最佳成績存在瀏覽器 localStorage。

## 請 Claude 解讀（選用）

截圖判讀頁的「請 Claude 解讀」會把截圖交給 Claude 看圖解說：

- 部署在 Vercel 時呼叫 `api/chart-read.js`，需在專案環境變數設定 `ANTHROPIC_API_KEY`。提示詞固定在伺服器端，前端只能送圖片與辨識摘要。這個端點沒有登入或流量限制，公開網址上任何人都能用你的金鑰呼叫，必要時請自行加上限制。
- 在 Claude 裡開啟這個頁面（Artifact）時，改用檢視者自己的 Claude 帳號。
- 直接用 `file://` 開啟時無法使用，其他功能不受影響。
