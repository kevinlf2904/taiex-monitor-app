# K線學堂 — 股票技術分析學習器

單一檔案的靜態網頁（`learner/index.html`），不需安裝套件或建置，直接用瀏覽器開啟即可；部署到 Vercel 後路徑為 `/learner/`。

## 功能

- **課程**：13 堂互動課（K線、反轉型態、持續型態與跳空缺口、均線、成交量、支撐壓力、RSI、KD、MACD、布林通道、背離、隱藏背離、風險與成本），每課附可互動的 K 線圖與自動標記的訊號，可按「換一段走勢」看更多例子。
  - 型態課有 17 種型態的示意卡片（錘子 / 吊人、倒狀錘子 / 流星、十字、吞噬、母子、貫穿 / 烏雲罩頂、晨星 / 夜星、紅三兵 / 黑三兵、跳空缺口），點卡片只標出該型態。
  - 背離課可切換 RSI / MACD / KD，在價格與指標上連出兩個轉折點；轉折點需右側 3 根 K 棒確認，標記畫在確認日，不偷看未來。
- **圖表實驗室**：自由開關均線 / 布林 / 支撐壓力 / RSI / KD / MACD，游標所在 K 棒會即時顯示多空判讀；可對 6 種策略做回測（隔日開盤成交，含 0.1425% 手續費與 0.3% 證交稅），並與買進持有比較。策略包含 K 線型態與 RSI / MACD 背離。
- **判讀挑戰**：看 120 天走勢，預測接下來 10 天漲或跌，揭曉後對照作答當天的指標檢討。
- **截圖判讀**：上傳、拖曳或貼上看盤軟體的 K 線截圖，瀏覽器內依紅綠像素找出每根 K 棒、還原開高低收（可輸入圖中最高 / 最低價校正），重算均線、RSI、KD、MACD、布林並產生判讀摘要；可框選 K 線區域重新辨識。圖片不會離開瀏覽器，除非按下「請 Claude 解讀」。
- **觀念測驗**：21 題題庫，每次隨機抽 12 題，附解析。

## 資料

價格皆為程式模擬（趨勢段落切換 + 波動叢聚，±10% 漲跌幅限制，價格貼齊台股升降單位），僅供學習，不代表任何個股。
學習進度、最佳成績存在瀏覽器 localStorage。

## 請 Claude 解讀（選用）

截圖判讀頁的「請 Claude 解讀」會把截圖交給 Claude 看圖解說：

- 部署在 Vercel 時呼叫 `api/chart-read.js`，需在專案環境變數設定 `ANTHROPIC_API_KEY`。提示詞固定在伺服器端，前端只能送圖片與辨識摘要。這個端點沒有登入或流量限制，公開網址上任何人都能用你的金鑰呼叫，必要時請自行加上限制。
- 在 Claude 裡開啟這個頁面（Artifact）時，改用檢視者自己的 Claude 帳號。
- 直接用 `file://` 開啟時無法使用，其他功能不受影響。
