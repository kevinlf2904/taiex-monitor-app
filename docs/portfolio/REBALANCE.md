# 目標配置與再平衡（投資研究第 2 批）

不用 AI、不送資料到外部服務。程式：`learner/rebal.js`（`KLRebal`，純函式）、`learner/pf-rebal.js`（配置頁的「目標配置與再平衡」區塊）。

## 設定
每檔持股填目標占總資產的百分比；空白＝不設目標（這檔維持原樣，不買不賣）。現金可以不填。
「偏離多少才調整」（預設 5 個百分點）：目前比重和目標差在這個範圍內就不動。
存檔：`kline:pf:targets:v1`，`{ v: 1, targets: { 代號或 CASH: 百分比 }, band, at }`；寫入前檢查（0～100、容許範圍 0～50）。
只存在這個瀏覽器；雲端同步與備份檔會一起帶，匯入時用 `KLRebal.validateStore` 完整檢查，沒有檢查程式不匯入。

## 計算
- 全部換成台幣：美股用目前匯率（沒有匯率的不能算，列出來）；沒有報價的不算（列出來）。總資產＝持股市值＋有記錄的現金（負現金照扣）。
- 要調整的金額＝目標比重 × 總資產 − 目前市值；股數＝金額 ÷（價格 × 匯率），往零的方向取整數（台股可以買零股；美股不假設券商支援碎股）。賣出不超過持有股數；不到一股就不動。
- 手續費與稅：用「交易紀錄」的費用規則（`KLLedger.estimateCosts`，含最低手續費、證交稅）。
- 調整後現金＝現金 − 買進（含費用）＋賣出（扣費用與稅）。不夠時標示「要先賣其他持股或入金」。
- 目標加總檢查：有設現金目標時，持股目標＋沒設目標的持股目前比重＋現金目標要等於 100%；沒設現金目標時不能超過 100%。

## 限制
用目前報價試算，實際成交價會不同，也沒算市場衝擊與稅務；不是投資建議。

## 測試
`tests/rebal.test.mjs`（手算：賣 200 股、手續費 28、證交稅 60、買 3 股、調整後現金；容許範圍、不設目標、全部賣出、不到一股、加總、現金不夠、沒有匯率或報價、存檔檢查）、`tests/e2e/pf-rebal.test.mjs`（390／1280 設定、建議與計算一致、擋下不合法、清除、備份檢查）。
