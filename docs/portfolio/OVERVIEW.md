# 投資組合總覽（第 8 階段）

程式：`learner/overview.js`（`KLOverview.summarize`，純函式）、`learner/pf-home.js`（畫面）。投資組合頁預設分頁改成「總覽」。

## 顯示內容
| 區塊 | 口徑 | 點進去 |
|---|---|---|
| 總資產（台幣） | 持股市值（美股 × 最新匯率）＋有追蹤的現金。沒有匯率時只算台股，另外標「美股 US$… 沒有換算」，不把美元當台幣相加。沒有報價的持股用成本估算並標示。 | 配置 |
| 今日損益 | 昨收就持有的股數 ×（現價 − 昨收）＋今天買進 ×（現價 − 買進價）＋今天賣出 ×（賣出價 − 昨收）；今天賣光的也算。報價日期不是今天的不算，列在風險狀態。 | — |
| 累積損益 | 已實現＋未實現＋股息（稅後）− 另計費用＋其他公司行動現金。美元部分用目前匯率換算（標示）；逐日匯率拆解看績效頁。 | 績效 |
| 現金比例 | 交易紀錄裡有入金時才計算現金；沒記入出金時現金不計。 | — |
| 市場分布 | 台股／美股／現金占總資產比例。 | — |
| 主要持倉 | 前五大，含占比、台幣市值、今日漲跌。 | 個股 |
| 風險狀態 | 單一持股 > 30%（> 50% 為高）、持股 ≥ 5 檔且前五大 > 80%、融資維持率接近或低於追繳線（試算）、沒有報價、報價不是今天的。 | 配置／融資／交易紀錄 |
| 資料時間 | 報價的行情時間範圍、匯率與日期、計算時間（台北）。 | — |

## 資料與隱私
- 報價、匯率沿用配置頁的快取（10 分鐘內共用），融資帳戶沿用 `kline:pf:margin:v1`；不新增存檔鍵、不上傳、不輸出 console。
- 測試：`tests/overview.test.mjs`（固定假資料）、`tests/e2e/pf-home.test.mjs`（390／1280）。
