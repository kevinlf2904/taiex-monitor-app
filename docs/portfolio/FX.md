# 匯率與台幣合併（第 3 階段）

實作：`learner/fx.js`（`window.KLFx`，要先載入 `ledger.js`、`perf.js`）；畫面在 `learner/ledger-ui.js`（績效頁最上面的「合併（台幣計價）」）。
測試：`tests/fx.test.mjs`、`tests/e2e/fx-ui.test.mjs`。

## 1. 口徑

| 項目 | 說明 |
|---|---|
| 匯率來源 | Yahoo Finance `TWD=X` 日收盤（`/api/kline?code=TWD=X`），是**市場中間價**，不是銀行實際買賣匯率；換匯成本（價差、手續費）沒有算進去。畫面會註明 |
| 匯率缺漏 | 當天沒有就用之前最近的一天；超過 5 天標「估算」（`fx_stale`）；最早幾天沒有匯率時用最早一筆並標示（`fx_missing_early`）；完全沒有匯率不合併（`no_fx`） |
| 換算 | 美股部位每天的市值與現金流，都用**當天**的匯率換成台幣；台股部位不換 |
| 台美休市日不同 | 沒開市的一邊沿用前一天的市值，現金流為 0 |
| 合併報酬 | 時間加權、資金加權都用 `perf.js` 同一套算法（含「唯一解證明不了就不給數字」） |
| 不能合併 | 台股或美股部位本身資料不足（例如零成本部位轉出又沒有價格）時，合併也標「無法計算」（`sleeve_unavailable`） |

## 2. 損益拆解（每天，可以完全對帳）

美股部位當天的台幣損益 ＝（今天市值 − 今天淨投入 − 昨天市值）× 今天匯率 ＋ 昨天市值 ×（今天匯率 − 昨天匯率）

- 前一項是「股價與股息」，後一項是「匯率」。
- 台股部位只有第一項。
- 台股損益＋美股股價與股息＋匯率影響＝合併總損益；美股兩項加總＝現在的台幣市值 − 當初投入的台幣（沒有拿回時）。

## 3. 「÷ 累計投入」

合併卡片上的「總損益 ÷ 累計投入」的分母是所有投入換成台幣的加總（買進、轉入，用當天匯率），不扣賣出與拿回的錢、也不看投入時點，只是損益的相對大小，**不是投資報酬率**；報酬率請看時間加權或資金加權報酬。

## 4. 還沒做

- 用銀行實際買賣匯率與換匯手續費（使用者自填）。
- 現金部位（台幣、美元存款）納入總資產。
- 其他幣別。
