# 投資論點追蹤與持股催化日曆（投資研究第 1 批）

使用者選定的第一批：不用 AI、不送資料到任何外部服務、不花費。程式：`learner/thesis.js`（`KLThesis`，純函式）、`learner/pf-thesis.js`（畫面），投資組合的「論點」分頁。

## 投資論點
每檔目前持有的股票可以記：
- **為什麼買**（文字，最多 2,000 字）
- **要觀察的**、**什麼情況代表論點不成立**（一行一項，各最多 20 項、每項 300 字）
- **狀態**：論點成立／觀察中／論點動搖／論點失效（自己判斷，不是系統算的）
- **下次檢視日**（預設 90 天後）
- **檢視紀錄**：日期、檢視後的狀態、看到什麼；加紀錄時可以把下次檢視日往後排 30／90／180 天；最多 200 筆，最新的在前面

存檔：`kline:pf:thesis:v1`（獨立前綴與版本），`{ v: 1, items: { 代號: {...} }, at }`。寫入前一定過 `KLThesis.validateStore`，不合格不寫。
只存在這個瀏覽器；`kline:pf:` 開頭的資料會跟著雲端同步（單項超過 150KB 的不會）與備份檔。匯入備份時用 `KLThesis.validateStore` 完整檢查，沒有檢查程式就不匯入（和交易紀錄、融資帳戶一樣）。

## 停損／停利（投資研究第 3 批）
論點表單可以替每檔設**停損**、**停利**，各自選「價格」或「相對平均成本的百分比」（停損打 10 存成 −10%，停利存成正的）。空白＝不設。
存在同一份論點資料（`stop`、`take`：`{ mode: "price"|"pct", v }`），百分比停損要在 −100%～0 之間、停利 0～1000%。

卡片上顯示兩個價位、現價還要跌／漲多少才碰到，以及狀態（`KLThesis.levels`）：
| 狀態 | 意思 |
|---|---|
| 已跌破停損／已漲過停利 | 現價 ≤ 停損價、≥ 停利價（等於也算） |
| 接近停損／接近停利 | 差 5% 以內 |
| 還沒觸及 | 其他 |
| 沒有報價／沒有成本 | 不硬算（百分比需要平均成本） |

報價和配置頁共用同一份（`lgAllocData`，`/api/quote`）。只有設了停損停利的人才會抓報價。
「設成到價提醒」把停損寫成「跌到」、停利寫成「漲到」，寫進個股頁同一份到價提醒（`watch:alerts`）；已經觸及的那一邊不寫；原本就有提醒會先跳確認、取消就不改。
**不會自動下單**，只是自己的紀錄與提醒。

## 財報指標（投資研究第 4 批）
台股持股的卡片帶入最新一期：月營收年增、累計營收年增、本季 EPS、毛利率、營益率、淨利率（年減或虧損標成下跌色）。
資料：`/api/oapi?earn=1`（證交所、櫃買中心開放資料合成的全市場表，和情報局「財報」同一份，一次載入，不逐檔查）。
「要觀察的」每一項用關鍵字對到指標（`KLThesis.matchWatch`：累計→毛利→營益／營業利益→淨利率／純益率→EPS／每股盈餘→營收），對到的在旁邊標「目前 xx」。對不到的不標。
美股、ETF、新上市或興櫃沒有這份資料，不顯示或說明「不在資料裡」；拿不到資料會標出來。只顯示公開數字，不判斷好壞、不是投資建議。

## 簡易估值（投資研究第 5 批）
台股持股的卡片顯示：
- **本益比、淨值比、殖利率**：`/api/screen?bw=1`（證交所 BWIBBU_ALL、櫃買中心本益比分析，每日公布；和選股「條件組合」共用）。
- **同產業本益比中位數**：產業用財報表（`/api/oapi?earn=1`）的產業別，至少 3 家才算，本益比 0 或沒有的不算。
- **歷史區間與情境價**（按「看歷史區間與情境價」才查，`/api/stockinfo`，和個股頁同一支）：至少 60 天的本益比才算；
  20%／50%／80% 分位（和個股頁的本益比色帶同一種算法）＝悲觀／中性／樂觀；情境價＝近四季 EPS（現價 ÷ 本益比反推）× 該分位本益比，另列用同產業中位數算的價格。
- 虧損（本益比沒有或 ≤ 0）不算情境價，改提示看淨值比。美股、ETF 沒有這份資料不顯示。

`KLThesis.valuation` 是純函式；只是粗估：沒算成長、利率與產業變化，不是目標價或投資建議。沒有做 DCF：現金流折現需要自己假設成長率與折現率，數字很容易被假設左右，先不放。

## 近期事件（60 天內）
只列**目前持有**的股票：
| 事件 | 來源 |
|---|---|
| 除權息 | `/api/calendar` 的 `rows`（證交所除權除息預告表、櫃買中心） |
| 法說會 | `/api/calendar` 的 `conf`（公開資訊觀測站法人說明會一覽表） |
| 美股財報日 | `data/us-earn.json`（排程整理的 Nasdaq 公開財報行事曆），讀不到或太舊才問 `/api/usearn` |
| 論點檢視日 | 自己設定的下次檢視日；已經過了的排在最前面並標「該檢視」 |

抓不到的資料會標示「這次拿不到，上面可能不完整」，不當成沒有事件。台股財報與月營收沒有逐家公布日，不列。
