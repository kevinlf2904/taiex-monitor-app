# 年度報稅彙整

從投資組合「總覽 → 報告（可列印）」最下面打開。程式：`learner/taxrpt.js`（`KLTaxRpt`，純函式）、`learner/pf-report.js`（畫面）。不用 AI、不連網、不存任何新資料（選的年份只留在這次開著的頁面）。

## 內容
- 年份：帳本裡出現過的年份；預設前一年（五月申報的是前一年的所得），沒有就用最新一年。
- 台股：現金股利總額、筆數、已扣款（交易的「稅」欄，通常是二代健保補充保費）；已實現損益（證券交易所得目前停徵，只供對帳）；手續費、證交稅。
- 美股：股息總額與預扣稅；已實現損益（獲利、虧損分開列，同一年度可互抵）。
- 海外所得（估）＝美股股息總額＋max(0, 美股已實現)，用目前匯率換算台幣；未達 100 萬元不用計入基本所得額。到了要不要繳稅還要看扣除額，以國稅局當年公告為準。
- 單筆 2 萬元以上、帳本沒記扣款的台股股利：提醒可能被扣了 2.11% 二代健保沒有記。
- 每檔明細與「下載 CSV」（有 BOM，Excel 可開；開頭是 = + - @ 的文字會加 ' 防止被當成公式）。

## 口徑
- 已實現、股息用 `KLLedger.buildReconciledLedger` 的 `positions[].history`（和投資組合其他分頁同一份）；股息總額與扣款從交易本身讀。
- 只整理帳本有記的交易，不是報稅建議；扣繳憑單、券商對帳單才是申報依據。
