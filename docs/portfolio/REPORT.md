# 投資組合報告（投資研究第 8 批）

不用 AI、不花錢、不存任何新資料。程式：`learner/report.js`（`KLReport`，純函式）、`learner/pf-report.js`（畫面）。從投資組合「總覽」最下面的「報告（可列印）」打開。

## 內容
- **總覽數字**：總資產、累積損益、現金比例、市場分布、匯率。用 `KLOverview.summarize`，和總覽頁同一口徑。
- **持股明細**：股數、均價、現價（沒有報價用成本估並標示）、台幣市值（美元用目前匯率；沒有匯率的不換算、不算比重並列出）、比重（含有記錄的現金）、未實現（市值 − 持有成本，不含已實現與股息）、論點狀態。
- **投資論點**：寫了幾檔、幾檔該檢視；每檔的狀態、下次檢視日、為什麼買的前 80 字；沒寫的列出來（讀 `kline:pf:thesis:v1`，只讀不寫）。
- **風險提醒**：和總覽頁一樣（單一持股、前五大、報價缺漏或過期）。

## 列印
- 「列印／存成 PDF」呼叫瀏覽器列印；列印時只印報告本身（分頁按鈕、導覽、按鈕都不印），白底黑字，漲紅跌綠。
- 報告只在這台裝置產生，不會上傳。

## 測試
- `tests/report.test.mjs`：市值、台幣換算、比重含現金、未實現、沒有報價用成本、沒有匯率不換算、負現金、論點摘要與到期、截字。
- `tests/e2e/pf-report.test.mjs`：390／1280 從總覽打開、明細和 `KLReport.build` 一致、論點摘要、列印按鈕、列印時只看得到報告、回總覽、不溢出。
