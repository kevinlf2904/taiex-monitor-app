# 還原股價（B0-1）

實作：`api/_lib/kline.js` 的 `parseYahooEvents`、`adjustRows`；前端 `learner/tools.js` 的 `dailyAdj`；測試：`tests/adj-price.test.mjs`、`tests/e2e/hold-adj.test.mjs`。

## 用法

`/api/kline?code=0050&months=6&adj=1`：每根日 K 多一個 `ac`（還原收盤價），並附上：

```
adj: { ok, source, events: [{ d, kind: "div"|"split", amt?, r?, f, applied? }], skipped: [...] }
```

- K 線圖、技術指標照舊用原始的 `o/h/l/c`。
- 報酬、波動、風險改用 `ac`。目前接上的是庫存風險（持股和美股基準 SPY）。

## 資料來源

| 股票 | 來源 |
|---|---|
| 上市個股（原始價格來自證交所） | 證交所官方參考價：TWT49U 除權除息計算結果表、TWTAUU 減資恢復買賣參考價。因子＝參考價 ÷ 前收盤，包含現金股息、配股、減資。分割仍用 Yahoo |
| 上櫃個股（原始價格來自櫃買中心） | 櫃買中心官方參考價：exDailyQ 除權除息計算結果、revivt 減資恢復買賣參考價（欄位格式已用 probe 確認） |
| 美股，或官方資料失敗 | Yahoo Finance 的除息與分割事件。台股拿不到官方資料時，畫面會寫「配股、減資可能沒有還原」 |

同一天有官方參考價時，Yahoo 的除息與分割就不再使用，避免配股被 Yahoo 記成分割而重複計算。Yahoo 已經調整過的價格（Yahoo 來源）不套官方參考價。

## 怎麼算

1. 事件來源：Yahoo Finance chart API 的 `events=div,split`（除息金額、分割比例）。
2. 分割：證交所、櫃買中心的原始價格，在分割日以前要除以比例（例如 0050 2025 年一拆四，就除以 4）。Yahoo 的價格已經依分割調整過，不再重複除。
3. 除息：除息日的因子是「1 − 股息 ÷ 前一個交易日收盤」，除息日以前的價格都乘上這個因子。除息日剛好不是交易日（或缺資料）時，算在下一個交易日。
4. 最後一根的 `ac` 等於原始收盤價。期間外的事件不處理，因為它們只會讓整段價格乘上同一個常數，不影響報酬。
5. 股息超過前收盤一半時，視為資料錯誤，略過並列在 `skipped`。

## 不還原、或還原不到的情況

- 加權指數、櫃買指數是價格指數，不還原，畫面會標示「價格指數，不含股息」。
- 拿不到除權息資料時，`adj.ok=false`、不給 `ac`，前端改用原始價格，並寫出是哪幾檔。
- 還原後仍有單日漲跌超過限制（台股 10.5%、美股 50%）的日子會列在 `adj.suspect`，多半是沒還原到的配股或減資（例如上櫃股）。畫面會寫出來，`portRisk` 的「異常單日」檢查也會拿掉這些日子。
- 股息資料不合理而沒還原的事件列在 `adj.skipped`，畫面也會寫出來。
