# 庫存各分頁改用交易紀錄（第 8 階段後半之一）

目標：有交易紀錄（`kline:pf:v1` 至少一筆交易）時，庫存的「持股」（損益、屬性分析；舊名即時損益、持股分析）「風險」「總經敏感度」、個股面板的持股列、
以及其他讀持股的地方（晨報、提醒、行事曆的「我的持股」）都改用交易紀錄算出來的持股，不再各算各的。

## 資料來源
- 交易紀錄模式：持股＝`KLLedger.buildLedger` 的未平倉部位，在記憶體裡換成舊格式 `{ 代號: { sh, cost, d, lg } }`：
  - `sh` 股數；`cost` 平均成本（含實際的買進手續費與稅，依帳本的成本算法）；`d` 這段持有的建倉日；`lg: true` 標示來自交易紀錄；`dv` 帳本記到的已領股息。
- 舊庫存 `kline:watch:hold`：**完全不動**，只讀。
  - `store.set` 加保護：交易紀錄模式下，任何寫入 `watch:hold` 的動作都會被擋下，避免把算出來的持股寫回舊資料。
- 沒有交易紀錄時，照舊用舊庫存，畫面與行為不變。

## 損益算法差異（避免重複計算）
- 交易紀錄的成本已含實際買進手續費與稅 → 不再估買進手續費；賣出手續費、證交稅照舊依設定估算（還沒賣）。
- 股息：「含股息」時用帳本記到的已領股息，不再用除息資料推估。

## 編輯
- 交易紀錄模式下，「編輯庫存」「截圖匯入」「載入範例」、個股面板的持股設定改成提示「到交易紀錄新增買賣」，不改舊庫存。
- 每個庫存分頁上方顯示：「持股來自交易紀錄（N 筆交易）」與「改看舊庫存」（只在這次開啟有效，不存檔）。

## 實作位置與測試
- `learner/watch.html`：`holdFromLedger`、`holdSrcApply`（存檔內容一模一樣就不重算，不每秒重算）、`holdSrcBar`、`holdLgBlock`；`holdPnL` 依 `h.lg` 調整；啟動時套用一次，庫存分頁每次重畫前確認。
- `learner/core.js`：`store.set` 支援 `store.lock`（回傳 false 就不寫），並回傳是否寫入。
- `learner/ledger-ui.js`：`lgSave` 存檔後通知庫存重算（`at` 是建立時間，不改）。
- 測試：`tests/e2e/hold-source.test.mjs`（交易紀錄模式、舊庫存不動、切換、交易紀錄改了跟著變、只有美股、沒有交易紀錄照舊）。

## 交易紀錄的台股／美股切換（第 8 階段後半之二）
- 「交易紀錄」「績效」上方有「全部／台股／美股」：篩選各幣別小計、持有中／已出清、交易清單（依幣別：台幣＝台股、美元＝美股）與績效卡片。
- 台幣合併（含匯率拆解）只在「全部」顯示。錯誤、待確認的提醒不分市場都顯示。
- 只在這次開啟有效，不存檔、不新增資料鍵。「總覽」「配置」「融資」本來就是整個投資組合，沒有切換。
- 庫存上方原本的台股／美股切換對交易紀錄沒有作用，在交易紀錄畫面藏起來。
